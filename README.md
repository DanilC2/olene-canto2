# Olene Canto — Frontend Website (Next.js)

A standalone **Next.js** website for **Olene Canto** featuring a luxury black-and-white theme, a hero section faithfully replicating the reference design, official brand logo integration, interactive categories, filterable menu, craft storytelling, real-time search, and reservation inquiries.

---

## 🌟 Key Features

1. **Reference-Faithful Hero Section**:
   - **Tagline**: `OLENE CANTO — SINCE 2014` (Artisanal culinary excellence)
   - **Headline**: *“Where Tradition Meets Taste”* (with elegant italic serif styling for *Meets Taste*)
   - **Evocative Brand Story**: Craft roastery to haute pâtisserie narrative.
   - **Twin Action CTAs**: `Explore Our Range →` (warm accent button) and `Our Story ↗` (glassmorphic button).
   - **Scroll Indicator**: Animated bouncing `SCROLL ⊙` indicator.
   - **Brand Logo**: Incorporates the official Olene Canto badge logo in the header capsule.

2. **Luxury Black & White Theme**:
   - Deep slate and onyx black backgrounds (`#080808` / `#0a0a0a`), crisp white typography, subtle warm glow accents, and frosted glass cards.
   - Serif typography powered by **Cormorant Garamond** paired with clean **Plus Jakarta Sans**.

3. **Interactive Features**:
   - **Header & Navigation**: Links (`BUSINESS`, `CATEGORIES`, `ABOUT US`, `PRESS RELEASE`, `CAREERS`), Language Selector, Inquiries/Reservations shortcut, and Real-time Search.
   - **Categories Filter**: Interactive category browser (Artisanal Brews, Haute Pâtisserie, Gourmet Savory, Botanical Elixirs, Confectionery & Gift Sets).
   - **Signature Collection Grid**: Filterable items with price tags, ratings, ingredients chips, calorie info, and Quick-View Modal.
   - **Heritage & Philosophy Showcase**: Craftsmanship breakdown, 4 key statistics, and 3 pillars of excellence.
   - **Interactive Inquiries & Booking Modal**: Allows guests to reserve private tables, tasting flights, or catering with instant confirmation.
   - **Instant Search Overlay**: Fast keyword search across recipes, roasts, and ingredients.
   - **Gastronomie Critic Reviews**: Testimonials from leading culinary and design journals.
   - **Footer & Private Salon Gazette**: Newsletter subscription, atelier operating hours, and location details.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### 3. Production Build
```bash
npm run build
npm start
```
